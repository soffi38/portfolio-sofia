Halo! 👋

Nama saya Sofia Ayu Lestari. Saya merupakan mahasiswa Program Studi Sistem Informasi di Fakultas Ilmu Komputer, Universitas Dian Nuswantoro.

Saya memiliki ketertarikan pada bidang pengembangan web, front-end, UI/UX, pemrograman, dan analisis sistem informasi. Saya senang mempelajari teknologi baru dan mencoba menerapkannya melalui berbagai tugas maupun proyek perkuliahan.

Bagi saya, teknologi bukan hanya tentang membuat sebuah sistem dapat berjalan, tetapi juga bagaimana sistem tersebut dapat memberikan pengalaman yang mudah dipahami dan digunakan oleh penggunanya.

Website ini dibuat sebagai bagian dari latihan mata kuliah Pemrograman Web untuk menerapkan berbagai elemen HTML5 secara terstruktur dan semantik.
